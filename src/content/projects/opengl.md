## The challenge

Created during the National University of Singapore’s Real-Time 3D Computer Graphics summer workshop, this project explores core real-time graphics techniques through practical implementation.

## My contribution

Worked with OpenGL programming, transformations, camera control, lighting, shadows, shaders, textures, framebuffers, and post-processing.

## Approach

The project materials document experiments spanning rasterization, shadow mapping, deferred shading and screen-space techniques.

## Outcome

The original source code is no longer available. The supplied report and a surviving video document a selection of the visual results.
